Visão Geral

Este projeto foi desenvolvido como uma solução de infraestrutura e software para Ambientes de aprendizado. O objetivo central é otimizar o suporte técnico escolar através de um ecossistema que integra monitoramento de hardware em tempo real, gestão de chamados e armazenamento seguro de dados confidenciais.

O diferencial técnico reside na separação lógica de rede implementada via software, permitindo segurança corporativa em um ambiente de hardware compartilhado.

Sistema em Operação

01 Tela inicial com resumo de chamados e tamperatura do rack em tempo real.
02 Fila de Chamados: Gestão centralizada de incidentes reportados pelos docentes.
03 Infraestrutura IoT: Módulos ESP32 configurados com IP estático no rack.

Funcionalidades Principais

Monitoramento IoT

Leitura em tempo real da temperatura do rack de servidores via sensores térmicos digitais.

Central de Chamados

Portal Web responsivo para docentes e um acionador físico (Botão de Pânico) via ESP32 para emergências.

Painel Administrativo

Dashboard centralizado para gestão de incidentes, telemetria IoT e controle de inventário da TI.

NAS Seguro

Servidor de arquivos restrito (Samba) para documentação técnica, blindado contra acesso de usuários comuns.

Arquitetura e Infraestrutura

O sistema utiliza uma topologia mista para garantir alta disponibilidade e segurança:

  • Servidor Central: Virtualizado em Linux Ubuntu, gerenciando API, Banco de Dados e Arquivos.
  • Segurança Lógica (Firewall): Implementação de regras via UFW para segregação de tráfego baseada em Host.
  • Gestão de IPs: Endereçamento estático para infraestrutura crítica e pool DHCP exclusivo para usuários (.100 a .200).

Desafios Técnicos Superados

Segregação de Redes sem VLANs

O desafio de isolar dados sensíveis em roteadores domésticos foi resolvido através de um Host-Based Firewall, configurando o servidor para filtrar acessos por endereços IP específicos.

Deploy de SPA em Servidores Estáticos

Superação do erro de rotas 404 do React através de um servidor web customizado em Python que gerencia o histórico de navegação.
